  "revised_document": "# Amber Architecture\n\nAmber is a library‑first tool. The `amber` binary wraps the library in\n`src/lib.rs` with a thin CLI.\n\n## Crate Layout\n\n```text\nsrc/\n├── lib.rs              # Public module re‑exports\n├── main.rs             # CLI entry point\n├── analysis/           # Project understanding\n│   ├── repo.rs         # Cargo metadata → dependency list\n│   ├── usage.rs        # AST visitor → CrateUsage\n│   └── types.rs        # Shared data types\n├── metadata/           # Enrich dependencies\n│   ├── mod.rs          # MetadataProvider trait\n│   ├── offline.rs      # Static, network‑free metadata\n│   ├── online.rs       # crates.io integration (feature `online`)\n│   └── rustsec.rs      # RustSec advisory DB integration\n├── scoring/            # Replaceability decisions\n│   ├── classifier.rs   # SafetyClassifier and ReplacementScore\n│   └── rules.rs        # Category lists and helpers\n├── replacement/        # Code generation\n│   ├── generator.rs    # Build ReplacementProposal objects\n│   ├── templates.rs    # Crate‑specific stubs\n│   └── validator.rs    # `cargo check` validation\n├── reporting/          # Output formats\n│   └── formatters.rs   # Console, JSON, PR, SARIF reporters\n├── config/             # User configuration\n│   └── mod.rs          # `.amber.toml` parsing and policy checks\n└── daemon.rs           # Optional monitor and Padagonia cache\n```\n\n## Data Flow\n\n```text\nCargo.toml ──► RepositoryAnalyzer ──► Vec<Dependency>\n                                         │\n                                         ▼\n                            UsageAnalyzer ──► HashMap<String, CrateUsage>\n                                         │\n                                         ▼\n                         SafetyClassifier ──► Vec<ReplacementScore>\n                                         │\n                    ┌────────────────────┼────────────────────┐\n                    ▼                    ▼                    ▼\n              ConsoleReporter      JsonReporter/PrReporter   Generator\n```\n\n1. **Repository analysis** reads `Cargo.toml` with `cargo_metadata`, resolves\n   direct and transitive dependencies, and fetches metadata.\n2. **Usage analysis** walks the project's `src/` with `syn`, recording imports,\n   function calls, method calls, macro invocations, type references, and\n   attributes.\n3. **Scoring** merges usage data and metadata into a multi‑dimensional score.\n   The tool blocks security‑sensitive crates and those with known advisories.\n4. **Reporting** outputs human‑readable tables, machine‑readable JSON/SARIF, or\n   pull‑request descriptions.\n5. **Replacement generation** writes `amber_<crate>.rs` modules and validates\n   them with `cargo check`.\n\n## Key Design Decisions\n\n- **Library‑first** – Core logic resides in `src/lib.rs`, enabling testing and\n  reuse in other tools.\n- **Offline by default** – Amber works without network access. Enable the\n  `online` feature to download data from crates.io.\n- **Security awareness** – RustSec advisory data enriches CVE counts. Any crate\n  with a known advisory receives the `SecurityCritical` classification.\n- **Heuristic attribution** – The tool attributes method calls to crates when\n  the receiver path or method name unambiguously maps to a tracked dependency.\n- **Confidence scoring** – Each score includes a confidence value derived from\n  usage visibility, independent of the overall replaceability score.\n- **Lightweight daemon** – The optional `daemon` feature adds a polling monitor\n  that discovers Cargo manifests, writes `.amber/daemon.toml` markers, fingerprints\n  dependency tables, and stores JSON snapshots in a Padagonia cache.\n\n## Adding a New Replacement Template\n\n1. Add a match arm in `ReplacementTemplate::generate_code`.\n2. Implement a private `replace_<crate>` method that returns a `String`.\n3. Verify that the generated code compiles on its own; the `Validator::validate`\n   step performs this check.\n4. Add an integration test that runs `amber replace <crate>` against a fixture.\n"
